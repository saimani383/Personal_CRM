# Personal CRM System

## Overview

The Personal CRM (Customer Relationship Management) System is a Full Stack Web Development project developed as part of my internship. The application helps users efficiently manage personal and professional contacts through a simple and user-friendly interface.

The system provides complete CRUD (Create, Read, Update, Delete) functionality along with search capabilities and a responsive dashboard.

---

## Features

- Dashboard with Total Contact Count
- Add New Contact
- View All Contacts
- Edit Contact Details
- Delete Contact with Confirmation
- Search Contacts
- Responsive User Interface
- MySQL Database Integration
